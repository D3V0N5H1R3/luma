## Run a Luma File

There are several ways to run a Luma program:

1. **Editor title bar** — click the **Play** button (▶) in the top-right corner of the editor when a `.luma` file is open.
2. **Keyboard shortcut** — press `Ctrl+Alt+R` (`Cmd+Alt+R` on macOS) with a `.luma` file focused.
3. **Command Palette** — press `Ctrl+Shift+P` (`Cmd+Shift+P` on macOS) and run **Luma: Run Current File**.
4. **Terminal** — run `luma path/to/file.luma` directly.

The program runs in an integrated terminal, and any compiler errors also appear in the **Problems** panel automatically. If the `luma` interpreter is not on your `PATH`, set its location with the `luma.path` setting.

## Write Your First Program

Create a file called `hello.luma` and add the following:

```luma
@main
function void main() {
    print("Hello, Luma!")
}
```

Every runnable Luma program has exactly one `@main` annotated function — execution begins there. Luma needs no semicolons, and `print` writes a line to the console.

Save the file (with the `.luma` extension) and you're ready to run it.
